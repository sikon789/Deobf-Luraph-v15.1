======================================================
  Luraph v15.1 反混淆工具 - 快速开始
======================================================

本工具需要 Python 3.8+，无需安装任何第三方库。

------------------------------------------------------
  用法
------------------------------------------------------

  python deob.py 样本.lua -o 输出.lua

工具会自动：
  1. 剥外层加密壳
  2. 判断样本形态（明文 / VM 字节码）
  3. 明文形态 → 完整解出源码
  4. VM 形态   → 明确告诉你解不了

------------------------------------------------------
  常用参数
------------------------------------------------------

  --list          只列出发现的大函数
  --force         形态 B 也强制导出骨架
  --no-rename     不做变量重命名
  --min-size N    大函数阈值（默认 20000 字节）

------------------------------------------------------
  示例
------------------------------------------------------

  试一下自带的形态 A 样本：

    python deob.py examples/SAE_layer3_示例.lua -o 输出.lua

  试一下形态 B（会被正确拒绝）：

    python deob.py examples/数字字面量变体_示例.txt -o 输出.lua

------------------------------------------------------
  结果说明
------------------------------------------------------

  返回码 0 = 成功解出源码
  返回码 2 = 没找到大函数（不是 Luraph v15.1）
  返回码 4 = 形态 B，业务代码在 VM 里，拒绝输出假结果
